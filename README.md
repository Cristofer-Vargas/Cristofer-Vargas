## Sobre mim

Meu nome é **Cristofer**, sou **desenvolvedor web full-stack** com foco em criar aplicações robustas, limpas e bem estruturadas. Tenho formação técnica em Informática pelo Senac RS e atualmente curso **Análise e Desenvolvimento de Sistemas**.

Minha jornada na tecnologia me proporcionou uma visão ampla e prática desde a infraestrutura até o desenvolvimento de software, com grande afinidade no desenvolvimento web e construção de APIs RESTful.

- **Desenvolvimento Web e APIs:** C# (.NET Core / MVC), PHP (Laravel), JavaScript/TypeScript
- **Desenvolvimento Desktop:** Java
- **Banco de Dados:** MySQL
- **Infraestrutura:** Manutenção de computadores e gerenciamento de redes

<br/>

## Projetos em Destaque

Aqui estão alguns dos projetos onde apliquei meus conhecimentos em backend, arquitetura de software e design responsivo:

- **[LudoVault](https://github.com/Cristofer-Vargas/LudoVault)**: Um catálogo de jogos inspirado no IGDB. Permite a customização de perfis e criação de listas/bibliotecas. Desenvolvido com **C#**, **ASP.NET Core**, **MVC** e integração via **API RESTful**.
- **[Convenção de Eventos](https://github.com/Cristofer-Vargas/convencao-eventos)**: Plataforma para registrar e gerenciar a participação do público em eventos. Construída utilizando **PHP**, **Laravel** e **Blade**.
- **[Controle de Contatos](https://github.com/Cristofer-Vargas/ControleDeContatos)**: Sistema focado em gerenciamento de dados de contatos, utilizando a arquitetura **ASP.NET MVC** com **C#**.
- **[Delivery SLG](https://github.com/Cristofer-Vargas/delivery-slg.com.br)**: Sistema de delivery online, desenvolvido como Projeto Integrador no Senac utilizando **PHP** puro.
